# MA 차트 구성과 버튼 설계 검토

2026-11-26 · Trading Universe에서 여는 종목별 MA 차트와 주요 지수 이평 창

**가장 먼저 개선할 곳은 기간 선택이다.** 기본값인 ‘1년’에서 휠로 확대하면 보이는 범위가 바뀐다. 이때 다시 ‘1년’을 골라도 같은 항목이어서 원래 범위로 돌아가지 않는다. 버튼을 추가하지 않고도 복귀 경로를 만들 수 있다. 다음으로는 ‘시장지수’와 ‘돌파 채널’을 어디서 켜는지 메뉴에서 드러내는 변경을 권한다.

## 현재 화면에서 유지할 부분

| 화면 영역 | 현재 구성과 설계 판단 |
|---|---|
| 종목과 시세 | 종목명·코드·시장·종가·등락을 머리 행에서 함께 읽는다. 종가는 항상 표시하므로 별도 토글이 필요 없다. 기준일은 조작 행 오른쪽에 있다. |
| 차트와 보조지표 | 가격 아래에 거래량·이격도·RSI가 있으며 사용 가능한 패널이 기본으로 켜진다. 지표를 꺼도 가격 패널의 자리를 유지해 같은 위치에서 전후를 비교할 수 있다. 가격선 오른쪽의 끝값과 공통 십자선도 이 비교에 유용하다. |
| 버튼 | 가격 위에 겹칠 선은 메뉴에서 복수 선택하고, 보조지표는 같은 폭의 버튼으로 즉시 켜고 끈다. 기간은 하나만 고른다. 이 차이가 각 조작의 성격에 맞는다. |
| 오른쪽 상세 | 국내 종목은 수급 자료가 있으면 투자자 표를, 적용 가능한 전략이 있으면 전략 점검을 보여 준다. WTI는 자료가 있을 때 선물 가격표를 보여 준다. 국내 종목의 기업 정보는 별도 탭에서 연다. |
| 주요 지수 이평 창 | 여러 지수의 종가·60일선·200일선을 나란히 보고, 전략에 따라 국내 지수의 시장 국면을 음영으로 읽는다. 여러 시장을 훑는 목적에는 개별 종목의 조작 행을 복제할 이유가 적다. |

## 우선 적용할 개선

### 1. 같은 기간을 다시 골라도 최근 구간으로 복귀시키기

합성 데이터 400개로 종목 창을 열어 휠 한 칸을 확대하자 가격축 범위가 365일에서 약 317일로 줄었고 콤보는 ‘1년’을 유지했다. 현재 기간 선택은 Qt의 `currentIndexChanged`에 연결돼 있다. 같은 항목을 다시 고르면 변경 신호가 없으므로 사용자는 다른 기간을 거쳐야 한다.

- **변경안** — 사용자 선택을 받는 `activated`에 기간 적용을 연결한다. 기간 콤보는 마지막 프리셋을 유지한다는 기존 결정을 살린다. 콤보 도움말은 ‘기간을 다시 선택하면 최근 구간으로 돌아갑니다’로 제안한다.
- **함께 고칠 부분** — ‘전체’에서는 이동 가능한 날짜가 없는데도 스크롤바가 활성 상태이고 최댓값은 10000이다. 실제 이동 여유가 없으면 비활성화하되 높이를 유지하고, 휠 확대로 이동 여유가 생기면 다시 활성화한다.
- **완료 기준** — ‘1년 → 확대 → 1년 재선택’과 ‘1년 → 과거로 이동 → 1년 재선택’ 모두 마지막 거래일 기준의 원래 범위를 복원한다. ‘전체 → 확대’ 후에는 스크롤바로 이동할 수 있다.

근거 구현은 [기간 콤보 연결](../../src/ui/dialogs/stock_ma.py)과 [기간 적용·스크롤바 계산](../../src/ui/dialogs/stock_ma_view.py)이다.

### 2. ‘이동평균’ 메뉴에서 비교선과 채널을 찾을 수 있게 하기

‘시장지수’를 겹쳐 보려는 사용자는 ‘이동평균’ 메뉴를 열어야 한다. 이 메뉴에는 MA20·MA60·MA200 외에도 자료에 따라 동일가중·시장지수·돌파 채널이 들어간다. ‘MA20 외 2’는 선택 개수를 알려 주지만 어떤 비교선이 켜졌는지 알려 주지는 않는다.

- **변경안** — 행 제목을 ‘가격선’(Price lines)으로 바꾸고, 열린 메뉴 안에서 ‘이동평균’, ‘비교선’, ‘채널’ 순으로 묶는다. 항목이 없는 묶음은 생략한다. 닫힌 버튼의 짧은 요약과 고정 폭은 유지하고, 툴팁과 접근성 설명에 선택 항목 전체를 표시한다.
- **완료 기준** — 시장지수가 있는 종목에서는 메뉴를 한 번 열어 MA60과 시장지수를 연속으로 선택할 수 있다. 상장 이력이 짧아 MA200을 계산할 수 없는 경우에는 기존 ‘데이터 부족’ 설명이 보인다. 한국어·영어 모두 선택 전후에 옆 버튼이 움직이지 않는다.

근거 구현은 [메뉴 생성과 선택 요약](../../src/ui/dialogs/stock_ma.py)이다.

### 3. 작은 창에서는 상세 표를 접고 차트를 넓힐 수 있게 하기

투자자 표는 긴 순매수 숫자를 끝까지 읽을 수 있도록 열 너비의 합을 최소 폭으로 사용한다. 투신·사모가 있으면 표가 5열에서 7열로 늘어난다. 오른쪽 영역은 분할선으로 접을 수 없고 왼쪽 조작 행도 한 줄로 고정돼 있어, 작은 화면에서 두 영역이 가로 공간을 경쟁한다. 실제로 잘리는 폭은 배율·언어별 측정이 필요하다.

- **변경안** — 상세 영역이 있는 창에만 ‘상세 접기 / 상세 펼치기’를 제공한다. 조작은 접힌 후에도 남는 차트 쪽에 두고, 다시 펼치면 사용자가 조절했던 폭을 복원한다. 처음 열 때는 현재처럼 상세를 보여 준다.
- **완료 기준** — 국내 7열 표에서 접고 펼쳐도 선택 기간, 켠 가격선, 전략 점검 결과가 유지된다. 1366×768 화면의 Windows 125%·150% 배율에서 한국어·영어 각각 기간 선택과 상세 복원이 가능한지 확인한다. 표와 전략이 모두 없는 창에는 버튼이 생기지 않아야 한다.

근거 구현은 [분할 영역과 한 줄 조작 행](../../src/ui/dialogs/stock_ma.py), [표 최소 폭 계산](../../src/ui/dialogs/stock_ma_side.py)이다.

## 검토 범위와 검증 수준

현재 소스와 [UI 설계 기록](../ui.md)의 5A·8.21~8.24·8.34절을 대조했다. 기간 확대와 전체 범위 스크롤바 상태는 PyQt 오프스크린에서 확인했다. 좁은 화면과 고배율에서의 가독성은 실기 검증 항목이다. 제안한 문구와 조작은 검토안이며 실제 앱에 적용하려면 위 완료 기준으로 확인해야 한다.
