### 1.6 구현 경계와 검토 보완 (2026-11-18)

- **전략 표시 데이터 전달**: `data/`는 전략을 import하지 않는다. UI도 현재 신호를 위해 특정 전략 패키지를 직접 import하지 않는다. `signal_api`의 공통 결과에 선택적 차트 오버레이를 추가하고 provider 내부에서 전략 함수와 파라미터를 재사용한다. 선의 날짜·값·라벨·유효 여부·판단 기준일을 전달하며 네트워크 조회는 기존 QThread 경로에서 수행한다. 기존 provider 결과에는 기본값을 제공해 현재 호출을 유지한다.
- **자료 기준**: 차트와 전략의 가격 조정 방식·통화·거래일·완성 일봉 기준을 일치시킨 입력에서만 값 일치를 보장한다. MA60 하나만으로 A 계열 L2 전체 조건을 충족했다고 표시하지 않는다. MA200은 개별주 차트의 참고선이며 BM3는 별도의 ETF 가격으로 판단한다.
- **워밍업**: 5년 조회 또는 665일 조회는 200개 유효 관측을 보장하지 않는다. 표시 시작일 이전 199개 유효 거래일과 국면 계산에 필요한 이전 주간 점검 상태를 확보한 뒤 전체 구간에서 계산하고 화면 범위로 자른다. 부족한 종목·지수는 해당 값을 결측으로 유지하고 ‘데이터 부족’으로 표시한다. 결측을 0으로 채우거나 거래정지 날짜를 임의로 제거해 전략 입력과 다른 창을 만들지 않는다.
- **국면 시점**: t일 종가로 확정한 상태와 다음 거래일 실행 가능 시점을 구분한다. 범례는 ‘L1 Risk-on(종가 판단)’으로 하고 A0의 L1 미사용과 다른 매수 조건의 존재를 툴팁에 설명한다. 미완성 주의 마지막 행이 자동으로 주간 점검일이 되는지 `weekly_check_days` 동작을 확인한다. 장중 잠정 일봉이나 잘린 날짜 배열로 계산한 음영을 확정 신호로 제시하지 않는다.
- **채널 표시**: 기본은 꺼짐으로 두고 상단·하단을 한 토글로 관리한다. 창 길이와 ‘직전·당일 제외’ 문구를 실제 파라미터에서 만든다. 채널은 가격 패널의 autoscale·hover·끝 값 라벨에 반영하고, 결측 구간은 연결하지 않는다. 지원 범위인 KOSPI·KOSDAQ 이외에는 숨긴다.
- **상태와 언어**: 새 표시 항목의 한글·영문을 `tr()`로 제공한다. 기존 저장 상태의 MA10 키는 복원 시 무시하고 유효 키만 복원한다. 언어 전환의 `export_state`/`import_state`에서 토글 선택을 보존한다. MA_RAMP는 다른 사용처를 조사해 기존 키의 색 의미를 보존하면서 필요한 키를 추가한다.
- **검증 추가**: 조회 199/200/201개, 신규 상장, 내부 결측, 휴일 주간, 미완성 주, 장중 잠정값, 차트 확대·기간 변경을 포함한다. 조회를 늘리거나 화면 왼쪽을 자를 때 같은 날짜의 값이 바뀌지 않는지 확인한다. 기존 MA50 Div와 RSI의 값·결측 마스크, 저장 상태 복원, 두 언어의 표시를 점검한다. 지수 MA200 첫 표시일 값은 충분한 이력이 확보된 테스트에서만 필수로 한다.

### 1.7 [1b] signal_api 확장 설계 (제안)

현재 `SignalProvider`는 종목 단위 메서드(`load`·`pick`·`check`·`templates`)만 있다. 차트 선은 종목 단위, 국면 음영은 **시장 단위**라 진입점을 따로 둔다. 둘 다 **선택 구현**으로 해 다른 provider는 수정하지 않아도 된다.

```python
# strategy/signal_api.py
@dataclass
class ChartLine:
    key: str                    # "breakout_high" | "exit_low"
    label: str                  # tr() 적용된 표시 이름: "직전 20일 최고가"
    dates: list[date]
    values: list[float | None]  # 결측은 None (선을 끊어 그림)
    style: str = "step"         # "step" | "line"
    provisional_from: date | None = None   # 이 날짜부터는 장중 잠정값

@dataclass
class RegimeSpan:
    start: date
    end: date                   # 포함
    on: bool                    # L1 Risk-on 여부
    provisional: bool = False   # 미완성 주·장중 값으로 판정한 구간

def chart_overlays(vid: str, ticker: str, market: str, ohlc) -> list[ChartLine]:
    """provider에 chart_overlays가 없으면 []."""

def regime_spans(vid: str, market: str, dates: list[date], index_close) -> list[RegimeSpan]:
    """provider에 regime_spans가 없으면 []. 시장 지수 하나의 L1 상태를 구간으로 반환."""
```

- **입력**: UI가 이미 받은 OHLC·지수 종가를 넘긴다(provider가 네트워크를 다시 조회하지 않음). 계산은 기존 QThread(`StockMaThread`·`IndexMaThread`) 안에서 호출한다.
- **변형(vid) 선택**: 종목 차트는 열 때 받은 `signal_ctx`의 변형을 쓴다. 지수 창은 문맥이 없으므로 `signal_api.default_variant()`를 쓰고, 그 변형이 L1을 쓰지 않으면(A0 등) 음영을 그리지 않고 범례에 '선택 변형은 시장 조건 없음'을 표시한다.
- **잠정값**: 마지막 일봉이 장중 값이면 `provisional_from`·`provisional`을 채운다. UI는 그 구간을 옅게(점선·투명도) 그리고 툴팁에 '잠정(장중)'을 붙인다.
- **라벨**: 창 길이 숫자는 provider가 `StrategyParams`에서 읽어 라벨에 넣는다(UI에 숫자를 쓰지 않음).
- **호환성**: 기존 `check`·`pick` 결과와 호출부는 바꾸지 않는다. provider가 메서드를 구현하지 않은 경우의 빈 결과를 테스트한다.

검증 실행(60일 값 적용·주변값 시험)은 가설 카드 승인 후 별도 이슈로 진행한다.


### 2.2 등록 및 호환성 보완

- H는 비용 1배의 전체 개발 구간과 사전 정의한 하위 구간에 적용한다. E2는 기준 60일 대비 주변값의 Sharpe 절대 변화가 0.5를 초과하는지 평가하고, 미수행과 실패를 별도 기록한다.
- ‘C의 성격 유지’를 정량 판정에 쓰려면 MDD·현금 비중·매매 횟수 등의 허용 차이를 실행 전에 정한다. 현재 카드에서는 설명 목적이며 채택은 H·E2와 감사 결과로 판단한다.
- 등록, 50일 기본값을 유지하는 이름 일반화, 60일 실험 구현을 각각 구분한다. 이름 일반화에는 `ScoreBook` 필드, 정책·IC·provider·테스트·리포트·저장 키의 모든 소비자를 조사하고 이전 필드의 호환 접근 또는 명시적 변환을 둔다. 같은 입력에서 값·결측·순위·주문이 동일한지 확인한다.
- v06과 v07을 함께 선택할 수 있으면 각 결과의 기간과 스펙 버전으로 표시 라벨을 만든다. Universe의 일반 MA50 Div를 전역 치환하려면 저장 뷰·필터 키·내보내기 열·캐시의 이전 값 처리까지 정한다. MA50을 제거하는 완료 조건에는 v06 표시 경로의 처리 방침도 포함한다.
- 신규 데이터에서 채택을 검토할 때 수정주가 시점 일관성·거래대금·유니버스 과제의 해결 여부를 보고한다. 과거 스냅샷의 단순 기간 비교와 새 데이터의 채택 검증은 각각 결과를 남긴다.

검토 근거는 `CLAUDE.md`의 의존 방향·signal_api 규칙, `signals.py`의 `regime_state`·`weekly_check_days`·`regime_cols`, `signal_api.py`의 결과 계약, `data/market.py`의 `fetch_index_mas`, `stock_ma_consts.py`의 기본 표시 정의다. 이번 개정은 구현 지시서와 연구 카드의 보완이며, 구현·신규 백테스트는 후속 작업이다.
