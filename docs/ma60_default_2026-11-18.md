# 추세선 60일 기본값 전환 — 구현 지시서 (2026-11-18)

대상: `src/strategy/trend_following/` (전략 코드·스펙), 화면은 2단계로 분리
관련: 스펙 10장(v07 등록·결과·판정), `docs/ma60_unification_2026-11-18.md`(화면 MA 정리), 보고서 `reports/추세추종_v07_검증결과_보고_v01.pptx`

## 1. 결정

- **사용자 결정 (2026-11-18)**: C 계열 점수의 장기 이동평균 `score_ma_long` 기본값을 **50 → 60**으로 바꾸고, 이 코드를 앞으로의 전략·SW 개발 기준으로 삼는다.
- 스펙 버전 갱신 규칙("규칙·파라미터가 바뀌면 현재 버전과 버전 이력에 한 줄")에 따라 **스펙 버전 v06 → v07**.
- **성과 판정과는 별개다.** 10-11 결과(C1′~C3′ 모두 H 미달)와 10-12 판정(채택 후보 아님)은 그대로 둔다. 이번 변경은 "목표를 통과해서 채택"이 아니라
  "기준선을 60일로 통일하는 사용자 결정"이며, 이 전략은 여전히 실거래 후보가 아니다. H 기준(Sharpe ≥ 1.5, |MDD| ≤ 15%)은 바꾸지 않는다.
- 새 버전 v07의 C1~C3 = 10-11의 C1L~C3L과 같은 설정이다. 따라서 **새 백테스트 없이** 10-11 수치가 v07 C1~C3의 개발 구간 결과가 된다
  (같은 코드·스냅샷에서 기본값만 바뀌므로). 확인 실행을 하면 E5에 '재현 실행'으로 따로 적는다.

## 2. 영향 범위

| 영역 | 영향 |
|---|---|
| A0~A5·B | 없음. `score_ma_long`은 점수 모드(C 계열)에서만 쓰인다. 9-19의 A·B 수치 그대로 |
| C1~C3 | 게이트(종가 > 60일선), 점수 pct(MA60Div), 매일 청산(종가 < 60일선)이 함께 바뀜. v06 C 수치(9-19)는 v06 기록으로 남김 |
| C1L~C3L | v07 C1~C3와 같아짐. 10-11 재현용 ID로 남기되 '= C1~C3 (v07)'로 표시 |
| E2 | N6(60→50)·N7(60→80)을 C1~C3에도 적용 → 기본 매트릭스(A0~C3) E2 시행 수 31 → 37 |
| Universe 추천·'전략 신호'·MA 차트 '전략 점검' | C 계열 신호가 60일 기준으로 바뀜(라벨은 이미 `MA{score_ma_long}Div`로 생성) |
| 화면 열·차트 메뉴 | 2단계(아래 4장)에서 처리 |

## 3. 1단계 — 전략 코드와 스펙

1. **`config.py`**
   - `SPEC_VERSION = "v07"`.
   - `StrategyParams.score_ma_long: int = 60`, 주석 `MA60Div = close / MA60 - 1 (trend direction, +)`.
   - `V07_VARIANTS`(C1L~C3L)는 유지(10-11 재현용). 설명 문구를 "v07 기본값과 같음(10-11 재현용)"으로 바꾼다.
   - `E2_NEIGHBORS`: N6·N7의 적용 변형에 C1·C2·C3를 추가(`("C1","C2","C3","C1L","C2L","C3L")`). 기준값 표시는 실효값(60)으로 나오는지 확인.
   - **v06 재현 수단**: `V06_C_VARIANTS = {"C1S","C2S","C3S"}`(각 C 행 + `("score_ma_long", 50)`)를 `RESEARCH_VARIANTS`에 추가해 9-19의 C1~C3를
     `--variants C1S,C2S,C3S`로 재현할 수 있게 한다. 화면 목록(`VARIANTS`)·`signal_api`에는 넣지 않는다.
2. **문구만 일반화 (필드 이름은 그대로, 10-8 별도 작업)**
   - `scoring.py`: 게이트 탈락 사유 `"MA50Div<0"`·`"No MA50"` → `f"MA{p.score_ma_long}Div<0"`·`f"No MA{p.score_ma_long}"`. 모듈·필드 docstring의 MA50 표기.
   - `scoring_policy.py`: 청산 사유 키 `REASON_MA50 = "ma50_exit"`는 저장·비교 호환을 위해 **값 유지**, 주석과 표시 라벨만 "추세선(score_ma_long일) 이탈".
   - `factor_ic.py`: `FACTOR_LABELS["ma50_div"]`를 `MA{score_ma_long}Div`로 생성.
   - 그 밖에 사용자에게 보이는 'MA50Div' 고정 문자열을 `rg "MA50"`으로 찾아 같은 방식으로 바꾼다(전략 패키지와 `signal_api` 범위).
3. **웜업**: 60일 창이 필요 세션 계산에 반영되는지 확인(`robustness`의 `score_ma_long` 람다, 데이터셋 웜업). 부족하면 '미수행'으로 표시되는 기존 동작 유지.
4. **스펙 `trend_following.md`**
   - 상단 표: 현재 버전 **v07**, 최종 수정일 2026-11-18, 상태에 "v07: 추세선 60일 기본값(사용자 결정 10-13), 성과 판정은 10-12 그대로(채택 후보 아님)".
   - 버전 이력에 v07 행: "2-5 `score_ma_long` 50→60(MA60Div) — 사용자 결정, 근거 10-11, H 미달·채택 후보 아님(10-12)".
   - 2-5장 본문의 MA50Div를 MA60Div로 덮어쓰기(본문은 최신 전략 기준 규칙). 9-19 v06 결과표에는 "(v06, 50일)" 표기만 추가.
   - 10장 머리 문구("이 장은 규칙이 아니다", "`score_ma_long = 50`")를 갱신하고 **10-13 "기본값 전환 (사용자 결정, 2026-11-18)"** 절을 추가:
     결정 내용, 10-12와의 관계(판정 유지), E2 31→37, C1S~C3S 재현 ID, 이번에 백테스트를 돌리지 않은 이유.
5. **테스트**
   - `test_v07_candidates.py`: "기본값 50" 단언을 60으로, "C′ = C + 60만 다름"을 "C1L == C1 (v07)"로 바꾼다. C1S~C3S = C 행 + 50만 다름.
   - 9-19 수치를 고정한 회귀 테스트가 있으면 C 계열은 C1S~C3S로 돌리게 바꾼다(A·B는 그대로 통과해야 함).
   - `test_robustness.py`: v06 매트릭스 E2 31회 → 37회, N6·N7 실효 기준 60.
   - 라벨: 기본값에서 'MA60Div', 사유 키 `ma50_exit`는 그대로.
   - 전체 pytest·ruff 통과.

**하지 않는 것**: H 기준·홀드아웃·A/B 규칙 변경, 실데이터 백테스트(확인 실행은 사용자 승인 후), 필드 이름 일반화(10-8), 화면 열·메뉴(2단계).

## 4. 2단계 — 화면 (스펙 10-5 '채택 시' 경로를 기본값 전환에 적용)

- Universe 표 `MA50 Div` 열 → `MA60 Div`: 계산 창 60, 저장 뷰·필터 키(`ma50div`)·내보내기 열·캐시의 이전 값 처리를 먼저 정한다

- MA 차트 '전략 점검'은 1단계에서 라벨이 자동으로 MA60Div가 된다 — 화면 확인만.
- MA 차트 이동평균 메뉴: 10-5는 MA50 제거를 제안했다. `docs/ma60_unification_2026-11-18.md` 1a의 MA20·MA50·MA60·MA200 구성에서
  MA50을 뺄지 사용자 결정 후 진행(권장: MA20·MA60·MA200만 남김 — 전략과 같은 기간만 보이게).
