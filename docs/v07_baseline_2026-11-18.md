## 1. 목적

- **사용자 결정 (2026-11-18)**: 앞으로 전략 개발은 **v07을 기준(basis)**으로 하고, v06은 중간 단계로 둔다.

  지금은 A·B 수치가 v06 원장(2026-10-14, 11-13 산식 수정 전), C 수치가 10-11 리포트로 출처가 나뉘어 있다.

## 3. 2단계 — v07 기준선 실행 (1회)

명령(1단계 커밋 위에서):
```
python -m strategy.trend_following.run --snapshot dev_2021_2024_nex23 --robustness --cash-interest-ref
```
(`--variants` 생략 = A0~C3 10개)

예상 시행 수(E5): 본 실행 10 × 비용 0·1·2배 = 30, E1 요일 10 × 4 = 40, E2 37, 현금 이자 0 참고 10 → **117회**. 실제 리포트의 E5 표와 대조한다.

**실행 후 확인 (불일치면 멈추고 보고, 수정·재실행 금지)**
- 스냅샷 SHA-256 = `a0de8fb8…`(10-1 등록값), 데이터 마지막 날 ≤ 2024-12-31, 홀드아웃 미사용.
- **C1~C3 비용 1배** = 10-11 C1L~C3L: Sharpe 0.44 / 0.41 / 0.41, MDD −13.8% / −15.3% / −17.8%.
- **A0~A5·B 비용 1배** = v06 원장(9-19)과 규칙이 같으므로 11-13 산식 수정(9-21) 범위 안에서 일치: 전략 Sharpe 차이 ≤ 0.001 수준,
  예) A1 Sharpe 0.98, CAGR 21.5%, MDD −18.6%. 연도별 인출·입금은 `docs/yearly_flows_report_2026-11-15.md` 5장 값과 만 원 단위로 일치.
- E2: A·B 행의 판정은 v06(NEX-58)과 같아야 하고, C1~C3 N6·N7은 10-11과 같아야 한다.
