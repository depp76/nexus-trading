# 연말 인출·입금 연도별 출력 — 구현 지시서 (2026-11-15)

대상: `src/strategy/trend_following/` 리포트 출력 (계산 로직·성과 수치는 바꾸지 않음)

## 1. 배경

스펙 9-2의 운용 가정은 "매년 1,000만 원으로 시작, 연말 마지막 거래일 종가로 초과분 인출·부족분 입금"이다. 엔진(`backtest.py` `_year_end_reset`)은 연도별 금액을 `BacktestResult.banked_by_year` / `topup_by_year`에 이미 기록한다. 그러나 출력에는 합계만 있다.

- `metrics.summarize_run`: `banked`, `topped_up` 합계만 반환
- `research.render_markdown`: "Cost breakdown" 표에 합계 열만 출력
- `robustness.py` 리포트(NEX-52/59 양식): 연도별 금액 없음

그래서 검증 리포트만으로는 "어느 해에 얼마를 빼고 채웠는지"를 확인할 수 없었다. 2026-11-15 보고서 작업 중 같은 스냅샷으로 재실행해 값을 뽑았고(아래 5장), 이를 정식 출력으로 옮긴다.

## 2. 출력 정의

연도 `y`마다, 운용 단위는 원(KRW)이다.

| 필드 | 정의 |
|---|---|
| `start_equity[y]` | 그해 첫 세션 시작 평가액. 2021은 시드(1,000만 원), 이후는 직전 해 리셋 직후 평가액(정수 주 잔여로 1,000만 원보다 클 수 있음) |
| `end_equity_pre[y]` | 그해 마지막 세션 종가 기준, 리셋 **직전** 평가액 |
| `banked[y]` / `topped_up[y]` | 엔진 기록값 그대로(`banked_by_year`, `topup_by_year`). 인출액에는 연말 트림 매도 비용이 이미 반영됨 |
| `net_flow[y]` | `banked[y] − topped_up[y]` |
| `residual[y]` | 리셋 직후 평가액 − 시드 (정수 주 때문에 남은 금액, 보통 0) |
| 마지막 해 | 데이터 끝이라 리셋을 하지 않는다. `net_flow`는 비우고 "평가 종료 차액 = 마지막 평가액 − 시드"를 따로 표시 |
| 4년 손익 | `Σ banked − Σ topped_up + (마지막 평가액 − 시드)` = 연도별 손익(`end_equity_pre − start_equity`)의 합 |

검산 관계: `end_equity_pre[y] / start_equity[y] − 1`은 `metrics.yearly_returns`와 같아야 한다(2026-11-15 확인: A1·B 일치).

## 3. 변경 범위

1. **`backtest.py`**: `_year_end_reset`에서 리셋 직전 평가액(`equity`)과 리셋 직후 평가액(`year_start_equity`)을 연도별 dict로 기록(`year_end_equity_by_year`, `year_start_equity_by_year`). 기존 계산·NAV 체인은 그대로.
2. **`metrics.summarize_run`**: `cash_flows_by_year` 키 추가 — 연도별 `{start, end_pre, banked, topped_up, residual}`과 마지막 해 `final_diff`, `total_pnl`. 기존 `banked`/`topped_up` 합계 키는 유지.
3. **`research.render_markdown`**: "Yearly returns (1x)" 다음에 "## Yearly cash flows (1x, KRW 만 원)" 표 추가. 열: ID, 연도별 순인출(+)/입금(−), 마지막 해는 "평가 종료 차액", 인출 합, 입금 합, 4년 손익. 전략과 BM1~BM3 포함, BM4 제외(무위험 상수).
4. **`robustness.py` 리포트**: 성과표 섹션 끝에 같은 표(1×)를 추가해, NEX-59 양식 검증 리포트에도 남게 한다.
5. **스펙 문서**: `trend_following.md` 9장에 새 절 추가(이 지시서 요약, 기대값 출처).
6. (선택) Strategy 탭 결과 상세에 같은 표 노출 — 별도 승인 후. 이번 범위에서는 하지 않는다.

하지 않는 것: 리셋 규칙·비용·체결 변경, 기존 수치 재해석, 0×/2× 표 추가(필요하면 후속).

## 4. 테스트

- **단위(합성 데이터)**: 2년짜리 가짜 가격으로 1년차 +, 2년차 − 시나리오를 만들어 `banked`/`topped_up`/`residual`/`final_diff`/`total_pnl` 관계와 `yearly_returns` 일치를 확인.
- **정수 주 잔여**: 고가 종목 1개 보유 시 `residual > 0`이 기록되는지.
- **회귀(스냅샷, 선택)**: `dev_2021_2024_nex23`이 있는 환경에서 아래 5장의 1× 값과 만 원 단위 반올림으로 일치하는지. 스냅샷이 없으면 skip.
- 기존 테스트 전부 통과, `ruff check src` 통과. 기존 성과 수치(Sharpe·CAGR·MDD) 변화 0.
