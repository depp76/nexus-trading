## 2. 개선안

### 2.1 구조: 3열 격자

```
┌ 실행 설정 ─┬ 데이터    기간 [   ]~[   ] │ 시장 [KOSPI|KOSDAQ|NASDAQ|NYSE] │ 유니버스 상위 [200] 유동성 하한 [100 억] │ ☐ 투자자 수급 (경고) ┬ [중지] [리서치 실행] ┐
│ 설정 접기   │ 규칙·실행 최대 보유 [6] 점검 요일 [월] 실행 비용 [0·1·2x|1x만] │ [변형 선택...] 요약 ……… ☑ 이벤트 스터디 │ 판정 목표 Sharpe ≥ [1.0] │                       │
└────────────┴──────────────────────────────────────────────────────────────────────────────────────────────────────────────┴──────────────────────┘
```

- **왼쪽 열**: "실행 설정" 제목과 그 아래 **설정 접기/펼치기 링크형 버튼**(밑줄 텍스트, `objectName="link"`, ACCENT_TEXT, 높이 제한 없음). 오른쪽과 `LINE_SOFT` 세로선으로 구분.
- **가운데 열**: 의미별 **두 줄**, 각 줄 앞에 작은 줄 이름(`TEXT_FAINT`, 8pt).
  - **데이터**(무엇을): 기간(+홀드아웃 포함) · 시장 · 유니버스 상위 · 유동성 하한 · 투자자 수급
  - **규칙·실행**(어떻게): 최대 보유 · 점검 요일 · 실행 비용 │ 변형 선택 + 요약 · 이벤트 스터디 │ 판정 목표 Sharpe
  - 줄 안의 묶음 사이 `LINE_SOFT` 세로 구분선(높이 20px, 좌우 6px) — 8.17의 "작업 묶음 사이 12~16px"을 선으로 보강.
  - 각 줄은 **자기 FlowLayout**: 좁은 창에서는 그 줄 안에서만 줄바꿈한다(데이터 묶음과 규칙 묶음이 섞이지 않음). 최소 폭 규칙(8.12: 묶음 하나)은 그대로.
- **오른쪽 열**: 중지 → 리서치 실행(8.17 순서·자리 유지 그대로), **두 줄 높이의 세로 가운데**, 왼쪽에 세로 구분선. → `set_first_line_inset` 제거(D4).

### 2.2 컨트롤

| 항목 | 현재 | 개선 |
|---|---|---|
| 시장 | 개별 checkable 버튼 4개 | 결과 줄과 같은 `SegmentRow(multi=True)` 붙은 세그먼트, 최소 하나 규칙 유지 |
| 체크 상태(전역) | ACCENT_BG + **ACCENT 테두리** + 600 | ACCENT_BG + **ACCENT_TEXT 글씨** + 테두리 `LINE_STRONG`(외곽선 강조 제거), 600 유지. primary만 밝은 테두리·흰 글씨 → 채움 버튼은 리서치 실행 하나로 보인다(D1). `segFocus` 2px ACCENT는 그대로 |
| 실행 비용 | 콤보 "0x / 1x / 2x", "1x만" | `SegmentRow` 단일 선택 [0·1·2x \| 1x만] (`_COST_CHOICES` 그대로) |
| 유니버스 라벨 | "유니버스" | "유니버스 상위"(값의 의미를 라벨에서) |
| 목표 Sharpe 라벨 | "목표 Sharpe ≥" | "판정 목표 Sharpe ≥"(입력이 아니라 결과 판정 기준임을 라벨에서, 8.17 이유와 같음) |
| 수급 경고 | 변형 요약 끝, 일반 색 | 투자자 수급 체크박스 **바로 뒤** `#warn` 라벨 "꺼져 있어 A3·A4·A5 제외" — 수급이 꺼져 있고 제외되는 변형이 있을 때만 보인다. 변형 요약은 "A0, A1, … (7/10)"만, 전체 문구는 툴팁 |
| 이벤트 스터디 | 수급과 한 묶음 | 변형 선택 요약 뒤(실행 항목) |
| 설정 접기 | 28px 외곽선 버튼, 제목 오른쪽 | 제목 아래 링크형 버튼, 폭 고정 규칙(긴 문구 기준)은 유지 |

### 2.3 칩 줄(접힘)

폼 순서와 같게 바꾼다: 기간 · 홀드아웃 · 시장 상위 N · 유동성 · 수급 │ 최대 · 점검 · 실행 비용 · 변형 · 이벤트 제외 · 목표 Sharpe.
칩도 가운데 열 첫 줄 자리에 놓고 오른쪽 열 버튼은 그대로라 접고 펼쳐도 버튼이 움직이지 않는다.

### 2.4 그대로 두는 것

primary 하나·중지 중립·실행 중 자리 유지(8.1·8.17), 기본 펼침(8.12), 홀드아웃 표시 규칙, 툴팁 문구, `basis_text()` 결과 기준 줄, 결과 줄(비교 대상·상세 기준·표시 비용·리포트 저장), 숫자 입력 고정 폭(`_SPIN_W`).

### 2.5 트레이드오프

- 높이: 보통 창(1440px)에서는 지금과 같은 2줄. 다만 좁은 창에서 두 줄이 **각각** 줄바꿈하므로, 단일 흐름보다 1줄 더 늘어날 수 있다(예: 1100px에서 3줄 → 4줄).
- 체크 상태 변경은 전역 QSS라 Universe·History의 토글/세그먼트 모양도 같이 바뀐다(의도한 일관성이지만 화면 확인 필요).

## 3. 구현 순서와 테스트

1. `theme.py` `QPushButton:checked` 수정, 링크형 버튼 `QPushButton#link` 추가.
2. `trend_following_tab.py` `_build_settings_card` / `_build_form`: 3열 `QGridLayout`, 가운데 열에 줄 2개(`FlowLayout` 각각, 앞에 줄 이름 라벨), 묶음 사이 구분선 위젯, `set_first_line_inset` 호출 제거. 시장·실행 비용을 `SegmentRow`로(시장 최소 하나 규칙, `selected_markets()`·`cost_combo` 사용처 이전).
3. 수급 경고 라벨(`flows_warn_lbl`, `#warn`)을 `_update_variants_label`에서 갱신, 변형 요약 문구에서 경고 부분 제거(툴팁에는 유지).
4. 칩 순서(`_update_chips`) 갱신.
5. 테스트: 기존 배치 테스트를 새 구조로 — 두 줄이 각자 줄바꿈, 탭 최소 폭이 묶음 하나 + 오른쪽 열 이하, 접힘/펼침 시 실행 버튼 좌표 불변, 수급 끔 + A3~A5 선택 시에만 경고 표시, 시장 마지막 하나 해제 불가, 비용 세그먼트가 `_COST_CHOICES`와 일치. offscreen 렌더 1440/1100/811px 스크린샷 확인.
6. `docs/ui.md`에 8.18 추가(8.12·8.17 해당 문장 개정 표시).
